# Capturas de las pantallas de la Previsión

Capturas de las pantallas hechas (rama `prevision-pantallas`, D-300 a D-309) con los datos de ejemplo
(`DemoDataSeeder`), para compararlas con las maquetas de `docs/diseno-prevision/capturas/`.

- `01-matriz-*`: `/prevision` (escritorio claro, tooltip en oscuro y móvil).
- `04-ficha-previsto-*`: la ficha de un previsto posible con su impacto «sin / con».
- `05-planificacion-y-estimado-*`: la pestaña Planificación de un proyecto que viene de un previsto, con «Estimado frente a real».
- `07-*`: «Mi carga» por asignaciones en Inicio y en `/carga` del empleado.
